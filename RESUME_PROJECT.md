# Resume Project Card

## Project
**AI-driven Building Energy Anomaly Detection & Low-carbon Decision System**

## One-line
Built an end-to-end AI decision-support pipeline for building-energy anomaly screening, counterfactual analysis and low-carbon intervention prioritization.

## Technical highlights
- Processed public building-energy data and built leakage-aware time-series features.
- Trained tree-based ML models with chronological validation.
- Developed robust anomaly detection using building-specific rolling baselines and MAD.
- Built energy fingerprints and intervention matching rules.
- Added counterfactual estimation, placebo calibration and uncertainty screening.
- Productized the workflow as a Streamlit dashboard.

## Important claim boundary
Do not write “saved X tons of CO2” unless verified field measurements exist. Use “estimated/scenario/conditional” for model-derived carbon values.
