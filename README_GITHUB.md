# GitHub presentation

An end-to-end portfolio implementation for AI-assisted building-energy diagnosis and low-carbon decision support.

The repository emphasizes reproducibility, leakage-aware time-series modeling, robust anomaly detection, explicit uncertainty, and a clear boundary between public-data screening and real-world causal validation.

## Quick start

1. Install dependencies.
2. Put the dataset at `data/test.csv`.
3. Run `python scripts/run_v3.py --input data/test.csv --output outputs`.
4. Run `streamlit run app/streamlit_app.py`.

Raw datasets and large generated artifacts are excluded from Git.
